# Vinnsýn web

This is Vinnsýn's public, static Vite/React visualization. It has no API
server. `data/market.json` is a reviewed
allowlisted snapshot generated by `../export_market.py`; it contains public
aggregates and indexed observation attributes only, never listing text,
personal workflow data, database credentials or private scores.

```bash
npm install
npm run dev
npm run build
```

The production `dist/` folder can be hosted as static files.
